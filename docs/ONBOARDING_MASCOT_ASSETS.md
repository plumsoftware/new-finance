# Ассеты маскота для онбординга (сова)

Замените файлы в `app/src/main/res/drawable-nodpi/` (или `drawable/`), сохранив **имена файлов** из таблицы ниже.

**Общие требования ко всем маскотам**
- Персонаж: **сова-коуч** — мудрая, спокойная, дружелюбная (не суровая бухгалтерша).
- Стиль: **плоский минимализм**, 2–3 цвета, без мелких деталей и без текстур.
- Контур: мягкий, округлый силуэт; глаза крупные, «дружелюбные».
- Палитра: основной `#007AFF` (iOS Blue) или нейтральный тёмно-серый `#3C3C43`; акцент успеха `#34C759` только на экране 3 (опционально).
- Фон PNG/WebP: **прозрачный**.
- Размер исходника: **512×512 px** (в UI показывается ~72–96 dp).
- Safe area: персонаж занимает **~70%** кадра, отступы по краям ~15%.

## 1. `onboarding_mascot_control.png` — экран «Контроль финансов»

**Сцена:** сова слегка выглядывает из-за нижнего края «графика» (как наблюдает за дашбордом).

**Поза:** голова и плечи видны; одно крыло опирается на воображаемую линию графика.

**Эмоция:** спокойная уверенность, лёгкая улыбка.

**Взгляд:** вверх-вправо на воображаемый растущий график (вне кадра маскота).

**Детали:**
- Мини-очки или без них (если с очками — тонкая оправа, 1 px, не доминирует).
- Без монет, мешков денег, крыльев «доллар».
- Цвет тела: светло-серый `#E5E5EA` или белый с тонкой обводкой для тёмной темы.

**Не делать:** паника, красные стрелки вниз, слёзы, калькулятор в лапах.

---

## 2. `onboarding_mascot_track.png` — экран «Доходы и расходы»

**Сцена:** сова держит **две плоские карточки** (или смотрит на них сбоку).

**Поза:** слева (в кадре) — маленькая зелёная карточка «+»; справа — нейтральная/серая «−»; сова между ними, жест «баланс».

**Эмоция:** ясность, порядок (не строгость).

**Детали:**
- Зелёный акцент только на «доходе» (`#34C759`), расход — `#8E8E93`, без агрессивного красного на маскоте.
- Лапа/крыло указывает на зелёную карточку.

**Не делать:** красное лицо, «запрет», перечёркивания.

---

## 3. `onboarding_mascot_smart.png` — экран «Умные покупки»

**Сцена:** сова рядом с **термокружкой** (главный символ киллер-фичи).

**Поза:** кружка по центру композиции маскота (~40% ширины), сова чуть сбоку, подмигивает или довольная.

**Эмоция:** «умная покупка» — хитрость в хорошем смысле, радость от экономии.

**Детали:**
- Кружка простая, без бренда; цвет `#007AFF` или белый с синей крышкой.
- Опционально: маленький «+150 ₽» как пузырь рядом (тонкий шрифт, не часть тела совы).
- Можно мини-иконку бутылки воды → фильтр (две иконки 24px) у ног, если влезает.

**Не делать:** пластиковая гора мусора, негатив про экологию.

**Эмоция:** воодушевляющая, «давай накопим».

## 5. Экран «Достижения» (страница 5)

**Маскот в коде:** `mascot_trophy.png` (уже в проекте).

**Сцена:** сова с кубком, рядом стрик и мини-карточки достижений.

**Эмоция:** праздничная, гордость за пользователя.

---

## 6. `onboarding_mascot_start.png` — экран «Начать»

**Сцена:** сова **машет крылом** (приветствие).

**Поза:** фронтально, чуть ниже центра; компактная, «приглашает войти».

**Эмоция:** тёплое «добро пожаловать».

**Детали:**
- Минимум элементов; можно маленький галочка-success `#34C759` рядом.
- Самый «чистый» кадр из четырёх — для финального CTA.

**Не делать:** paywall, замки, «премиум» короны.

## Техническая подстановка в проект

| Файл в res | Экран |
|------------|--------|
| `onboarding_mascot_control` | 1 — Контроль |
| `onboarding_mascot_track` | 2 — Учёт |
| `onboarding_mascot_smart` | 3 — Умные покупки |
| `mascot_happy` | 4 — Цели |
| `mascot_trophy` | 5 — Достижения |
| `onboarding_mascot_start` | 6 — Начать |

Форматы: **WebP** (предпочтительно) или PNG. Для `@2x/@3x` можно положить в `drawable-xxhdpi` и выше.
