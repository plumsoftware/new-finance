# Импорт и Экспорт данных

Документ описывает состав резервной копии (`.owlbackup` / `.json`) и поведение импорта.

## Что входит в экспорт

- категории
- операции
- повторяющиеся операции
- эко-активы и история их использований
- лимиты категорий
- цели
- пополнения целей

Примечание: выбранный период экспорта влияет только на операции. Справочные сущности (категории, лимиты, цели, настройки сущностей) экспортируются полностью.

## Формат файла

- текущая версия формата: `3`
- сериализация: JSON (`.owlbackup` — это JSON с другим расширением)
- основной объект содержит:
  - `meta`
  - `categories`
  - `transactions`
  - `recurringTransactions`
  - `assets`
  - `assetUsageHistory`
  - `limits`
  - `goals`
  - `goalDeposits`

## Совместимость

- если в старом файле отсутствуют `limits`, `goals` или `goalDeposits`, импорт продолжится (поля считаются пустыми)
- если версия файла выше поддерживаемой, импорт отклоняется

## Стратегии импорта

- `MERGE` — добавляет новые записи, дубликаты пропускает
- `REPLACE` — обновляет совпавшие записи, отсутствующие добавляет
- `OVERWRITE` — очищает локальные данные и записывает данные из файла

## Технические точки в коде

- доменные модели бэкапа: `domain/model/BackupModels.kt`
- сериализация/десериализация: `data/backup/BackupSerializer.kt`
- сборка/применение бэкапа: `data/repository/BackupRepositoryImpl.kt`
- UI экспорта: `presentation/export/ExportScreen.kt`
- UI импорта: `presentation/importdata/ImportPickerSheet.kt`, `presentation/importdata/ImportPreviewScreen.kt`
