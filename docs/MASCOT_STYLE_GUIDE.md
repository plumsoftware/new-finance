# Маскот приложения: сова-коуч «Филин» (рабочее имя)

Единый гайд для всех иллюстраций, онбординга, пустых экранов, push и микро-анимаций.

---

## 1. Роль персонажа в продукте

**Кто:** не бухгалтер и не «контролёр трат», а **спокойный финансовый наставник** — помогает видеть картину целиком, радуется умным покупкам и маленьким победам.

**Эмоциональная задача:** снять стресс от учёта денег, дать ощущение «у меня всё под контролем» и лёгкого дофамина от экономии.

**Голос бренда через маскота:** короткие фразы, без морали, без паники. Примеры тона: «Отличный ход», «Кружка почти окупилась», «Спокойно, мы всё видим».

---

## 2. Стиль рисовки (общий)

| Параметр | Значение |
|----------|----------|
| **Жанр** | Плоская иллюстрация (flat), 2D |
| **Детализация** | Низкая–средняя: читается на 24×24 dp и на 512×512 px |
| **Линия** | Опционально тонкая обводка **1.5–2 px** цветом `#3C3C43` (15% opacity в светлой теме) или без обводки — только формы |
| **Тени** | Мягкая **одна** тень под персонажем: `#000000` 8–12% blur, offset Y 4px — не «мультфильм», не реализм |
| **Градиенты** | Максимум **один** мягкий градиент на теле (светлее к животу) или полностью заливка |
| **Текстуры** | Нет перьев поштучно, нет шума, нет фото-реализма |
| **Референс по ощущению** | Apple Health / Headspace / современные fintech-иллюстрации (Monzo, N26 empty states) — **не** Pixar, **не** аниме, **не** мемные стикеры |
| **Геометрия** | Круглая голова ~60% высоты силуэта, короткое тельце, крылья как **упрощённые лепестки**, лапы — 2–3 пальца |

---

## 3. Фон иллюстрации

| Контекст | Фон |
|----------|-----|
| **PNG/WebP для UI** | **Полностью прозрачный** — обязательно |
| **Экспорт** | Без «подложки-круга» под совой (круг рисует UI в карточке) |
| **Онбординг** | Маскот лежит поверх **белой/тёмно-серой карточки** приложения — не рисовать свой градиентный фон в файле |
| **Исключение** | Для маркетинга (стор, сайт) — опционально очень светлый `#F2F2F7` с круглым «пятном» `#FFFFFF` за персонажем |

**Не использовать:** космос, лес, офис, полноэкранные сцены — маскот **персонаж**, не иллюстрация-обои.

---

## 4. Палитра на маскоте

### Основные цвета персонажа

| Элемент | Light theme (основной экспорт) | Dark theme (опционально второй набор) |
|---------|-------------------------------|----------------------------------------|
| **Тело / голова** | `#E5E5EA` (системный серый iOS) или `#FFFFFF` | `#2C2C2E` |
| **Живот (брюшко)** | `#FFFFFF` или на тон светлее тела | `#3A3A3C` |
| **Обводка / контур** | `#3C3C43` @ 80% или `#8E8E93` | `#EBEBF5` @ 60% |
| **Глаза — белок** | `#FFFFFF` | `#FFFFFF` |
| **Зрачок** | `#1C1C1E` | `#1C1C1E` |
| **Клюв** | `#FF9F0A` (мягкий оранжевый, не кислотный) | тот же |
| **Лапы** | `#FF9F0A` или `#8E8E93` | тот же |

### Акцентные цвета бренда (детали, реквизит)

| Назначение | HEX | Где на маскоте |
|------------|-----|----------------|
| **Primary / действие** | `#007AFF` (iOS Blue) | Очки, бант, кружка, иконки рядом |
| **Успех / доход / экономия** | `#34C759` (iOS Green) | Галочка, «+», маленький пузырь суммы |
| **Расход (осторожно)** | `#FF3B30` | **Не на теле совы** — только на реквизите (минус на карточке) |

**Правило:** на **перьях/теле** не больше **2 цветов** + клюв. Акценты — в **предметах** (кружка, карточки, пузыри).

## 5. Анатомия и пропорции

```
        ┌─────────────┐
        │   голова    │  ~60% высоты
        │  ●     ●    │  глаза: расстояние = 1/3 ширины головы
        │     ∨       │  клюв: маленький, высота ~12% головы
        └──────┬──────┘
           ╱   │   ╲
        крыло тело крыло     тело ~25%, крылья ~30% ширины каждое
           │   │   │
           лапа лапа
```

- **Высота полного роста:** голова + видимая верхняя часть тела (часто **по пояс** или **грудь** — ноги не обязательны).
- **Глаза:** крупные, **40–45%** ширины лица — главный носитель эмоции.
- **Клюв:** короткий, слегка улыбающийся (нижняя челюсть мягкая дуга).
- **Крылья:** прижаты к телу или одно поднято (приветствие) — не размах на весь кадр.
- **Хвост / перья:** не детализировать — 2–3 «лепестка» сзади максимум.

---

## 6. Выражение лица (набор эмоций)

| Состояние | Брови | Глаза | Клюв | Когда |
|-----------|-------|-------|------|--------|
| **Neutral / коуч** | мягкая дуга | круглые, спокойный взгляд | лёгкая улыбка | дашборд, подсказки |
| **Happy / победа** | приподняты | чуть прищур «радость» | открытая улыбка | окупилось, +сэкономил |
| **Thinking** | одна приподнята | взгляд вверх-вбок | нейтральный | онбординг, обучение |
| **Wink** | одна дуга | один глаз закрыт линией | ухмылка | умные покупки |
| **Welcome** | нейтраль | широко открыты | улыбка | экран «Начать» |

**Запрещено:** слёзы, гнев, красное лицо, пот, знак «стоп», пальцы «нет», шок с открытым ртом.

---

## 7. Аксессуары (фирменные, не перегружать)

- **Очки:** тонкая оправа `#007AFF` или `#3C3C43` — **не обязательны**, максимум в 30% иллюстраций.
- **Реквизит:** термокружка, две плоские карточки, мини-график — **в лапах или рядом**, не внутри тела.
- **Бейджи:** маленький круг `#34C759` с белой галочкой — отдельный слой, не часть силуэта.

Один аксессуар на кадр (правило).

## 8. Положение в макете (онбординг и UI)

| Экран / зона | Размер в UI | Позиция | Ориентация |
|--------------|-------------|---------|------------|
| Онбординг 1–3 | **88×88 dp** | Нижний угол иллюстрации: **справа** или **слева** (чередовать) | 3/4, лицом к контенту |
| Онбординг 4 | **88 dp** | По центру **под** галочкой | Фронтально |
| Пустой экран | 120–160 dp | Центр или чуть выше центра | Фронтально |
| Snackbar / tip | 32–40 dp | Слева от текста | Только голова |
| App icon (будущее) | 1024 px | Центр, **голова + крылья**, без мелкого текста | Симметрия |

**Отступы:** минимум **16 dp** от краёв карточки; не обрезать клюв и крыло.

**Взгляд:** всегда на **полезное действие** (график, зелёную карточку, кнопку «+ сэкономил»), не в пустоту.

---

## 9. Согласованность с UI приложения

- Фон приложения: `#F2F2F7` (light) / `#000000` (dark).
- Карточки: `#FFFFFF` / `#1C1C1E`, скругление **20 dp** — маскот не дублирует скругление своим фоном.
- Шрифт рядом с маскотом: **Inter** — на иллюстрации **нет** надписей (кроме микро-пузыря «+150 ₽» как графический элемент, не строка в шрифте Inter).

---

## 10. Технический экспорт

| Параметр | Значение |
|----------|----------|
| Формат | **WebP** (предпочтительно) или PNG-24 |
| Разрешение | **512×512 px** (мастер), при необходимости 1024 для маркетинга |
| Цветовое пространство | sRGB |
| Имя слоёв (Figma) | `mascot/body`, `mascot/eyes`, `mascot/beak`, `prop/*` |
| Safe zone | 10% отступ от краёв canvas — клюв и крылья внутри |

---

## 11. Чего избегать (антипаттерны)

- Мешки денег, монеты, «золотые» крылья.
- Реалистичная сова с детальными перьями.
- Агрессивный красный на теле персонажа.
- Детский «мультяшный» стиль с огромным ртом.
- Полная сцена (лес, город) внутри файла маскота.
- Текст внутри PNG (кроме декоративного пузыря-суммы без привязки к локализации).
- Разный стиль линии между экранами (сегодня с обводкой, завтра без).

---

## 12. Краткий brief одной строкой для дизайнера

> Плоская iOS-совместимая сова-коуч, спокойная и дружелюбная, 2–3 цвета на теле, прозрачный фон, крупные глаза, мягкая улыбка, один реквизит (кружка/карточки), акценты только `#007AFF` и `#34C759` в предметах, без стресса и без «денежной жадности».
